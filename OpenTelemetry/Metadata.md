| Term                      | Meaning                                                                                                               |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Attribute**             | OpenTelemetry's name for metadata: key–value information attached to telemetry                                        |
| **Dimension** / **Label** | The terms metrics use for attributes                                                                                  |
| **Field**                 | The term log records use for their metadata                                                                           |
| **Resource**              | Attributes that describe the entity producing telemetry, such as a service or a container                             |
| **Semantic conventions**  | Standard names and values for metadata, so telemetry stays vendor-neutral                                             |
| **Cardinality**           | The number of unique values an attribute, or a set of attributes, can take. High cardinality costs memory and storage |
| **Baggage**               | A way to pass metadata between services, to show causal relationships between events                                  |

| Term           | Meaning                                                                                                    |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| **Signal**     | One of the categories of telemetry: traces, metrics, or logs                                               |
| **Trace**      | A directed acyclic graph of spans, where the edges are parent–child relationships                          |
| **Span**       | A single operation within a trace                                                                          |
| **Span link**  | A link between spans that are causally related                                                             |
| **Metric**     | A raw measurement or predefined aggregation, recorded as a time series with metadata                       |
| **Log record** | A timestamped, severity-tagged recording of data, which can include a trace ID and span ID for correlation |
| **Event**      | A log record with an event name and a well-known structure                                                 |
| **Status**     | The result of an operation, typically whether there was an error                                           |
